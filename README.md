# Dorsey Duo Games

Free browser games made by Dorsey Duo Games.

## Chrono Vault: Echo Heist

Chrono Vault is the opening mission in Echo Heist, a time-loop stealth puzzle game. Record a route, rewind time, and work alongside your past echoes to distract guards, unlock the vault, steal the Core, and escape.

The complete game includes four unlocked missions: Chrono Vault, Neon Foundry, Mirror Archive, and Zero Hour.

**[Play Chrono Vault: Echo Heist](https://decodev2012.github.io/dorseyduo_games/time-loop-heist/)**
